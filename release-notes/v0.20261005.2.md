AMD hosts are supported. Mac OS X 10.9 Mavericks builds and boots on a Linux
host with an AMD CPU and AMD-V, measured on GitHub's hosted runners.

- The host check now accepts AMD-V (`svm`) as well as Intel's VT-x.
- Both templates' default `cpu` adds `vendor=GenuineIntel`. On AMD it is
  required: without it, 10.9 hangs before its kernel prints a line. On Intel
  it changes nothing. If you set your own `cpu` on an AMD host, keep it.
- A guest built on one CPU vendor boots on the other.

Snow Leopard has the same default and has not yet been tried on AMD.

The image, and any box made from it, contain Apple's operating system. Never
publish either one.
