Nothing a box does has changed. This release changes only a comment in
the Aqua Transport layer's template, `mavericks-aquatransport`, which now
says that nothing in that template's directory is part of the base recipe.

That comment is the release's whole purpose: it proves the base recipe
works as v0.20261005.6 promised. This release's base recipe is the same as
v0.20261005.6's, because nothing the Mavericks base image is built from
changed. So mavericks-vm, given this release, pulled its cached base image
and built only the Aqua Transport layer over it, in about 15 minutes
instead of about 53.

The image, and any box made from it, contain Apple's operating system. Never
publish either one.
