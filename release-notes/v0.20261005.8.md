Nothing a box does has changed. Every script in the repository now says
where it runs, in a `# platform:` line in its header: the build host
(`host-agnostic`), or only macOS (`macOS-only -- <why>`). That includes
the scripts that run inside the guest and inside the privops microVM. This
is the Mavergreen family's check 22, which now fails the build when a new
script doesn't say where it runs.

That line changes the bytes of the guest's install-time scripts and the
microVM's, so this release's media and base image have new keys:

- Every cached `mavericks-media` entry is built again, once, on its first
  build with this release.
- The base recipe changes, so mavericks-vm builds its cached base image
  and the Aqua Transport layer over it again, once.

v0.20261005.7, the release before this one, changed only a comment in the
Aqua Transport layer's template. It kept v0.20261005.6's base recipe, so
mavericks-vm rebuilt only the layer for it.

The image, and any box made from it, contain Apple's operating system. Never
publish either one.
