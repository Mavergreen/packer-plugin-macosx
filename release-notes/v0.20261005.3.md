The Mavericks box is 12% smaller. The build zeroes the guest's free space
before it shuts down, so the image compresses better: 7.59 GB to 6.74 GB for
the box, 6.83 GB to 6.03 GB with zstd, for about two minutes more build.

Also measured since the last release, and written into the docs:

- Guest CPU models of Nehalem and later need `kvm.ignore_msrs=Y` on the host
  to boot a guest built with Security Update 2016-004 (13F1911): its kernel
  reads `MSR_FLEX_RATIO`, which KVM does not emulate on Intel or AMD. The
  default, Penryn, never reads it.

The image, and any box made from it, contain Apple's operating system. Never
publish either one.
