## What improves

- **Faster, more reliable boots and shutdowns.** Cold starts are about 30 seconds faster. Fixes address intermittent firmware restart hangs, long shutdown stalls, missing early-boot logs, and startup crashes. Mavericks power/usage-statistics collection is disabled to avoid crashes and stalls.
- **Complete Snow Leopard security updates.** Security Update 2013-004 now installs after the 10.6.8 restart instead of being partly overwritten. Builds take an extra boot and stop if a prerequisite update fails. SSH startup is also more reliable.
- **Usable guest windows.** Snow Leopard now accepts keyboard and pointer input. Keyboard Setup Assistant no longer interrupts either release. Automatic login is enabled only with a verified password; otherwise boxes stop at the login window.
- **OpenSSH 10.6p1.** Includes security fixes and avoids starting `sandboxd` on first login. SSH now rejects usernames containing `$` or `\`.
- **Clearer build failures.** Failed installs stop promptly and preserve `output-mavericks-install.log` or `output-snowleopard-install.log`. Build guests no longer access the internet; finished boxes retain normal networking. Mavericks security-update installation can take about three minutes longer.

For manual shutdowns, use `sudo /usr/local/sbin/guest-macosx-shutdown -h` (`-r` to restart). Bare system commands do not get its shutdown workarounds.

For boot-gate users, `bin/gate.sh` now checks both releases and requires `--installer <your Snow Leopard disc image>`.

## Upgrading

Rebuild your boxes to get these fixes. Existing boxes stay unchanged.

1. **Rebuild the Mavericks base before its Aqua Transport layer.** Older bases are now refused. For an existing Vagrant box, import the rebuilt box with `vagrant box add --force`.
2. **Update renamed environment variables:**
   - `MAVERICKS_DISPLAY` → `GUEST_MACOSX_GUI=1` to open a window. Use `GUEST_MACOSX_QEMU_DISPLAY` to choose a display backend or VNC.
   - `MAVERICKS_CPU_ISA` → `GUEST_MACOSX_CPU_ISA` (`none`, `avx`, or `avx2`; Snow Leopard ignores it).
3. **Expect a one-time cache rebuild.** The default cache moves from `mavericks/` to `guest-macosx/`. Reuse existing downloads by moving the contents of `mavericks/cache/` into `guest-macosx/cache/` first. Long paths may require a shorter `PACKER_CACHE_DIR`; the build reports the limit. Guest files were renamed on 2026-10-17 from `mqg` to `guest-macosx`.

## Known limits

- Some Apple background-service delays remain, including Snow Leopard's critical updater. Shutdowns are not guaranteed stall-free.
- The USB tablet pointer remains slightly offset.
- **Vagrant's forwarded SSH port may listen on every host interface.** Use a firewall or trusted network; do not assume it is host-private.

Images and boxes contain Apple's operating system. **Never publish them.**
