## What improves

- **A failed build can be diagnosed.** Every build now opens a QEMU monitor socket at `output-<template>-qmp/qmp.sock`. The plugin creates that directory owner-only (mode 0700), whatever your umask, and refuses it if it is a symlink, belongs to another user, or sits in a directory anyone can write to, such as `/tmp` itself. While a build runs, you can inspect a stalled guest without stopping it. The socket adds no device the guest can see.
- **Each template zip now includes `gate-build-evidence.sh`**, the reader that collects that evidence. `SHA256SUMS` covers the zips, so the reader is verified with them. `qmp` reads the live QEMU, and `disk` reads the guest's logs from its disk with no root (Linux: needs FUSE and 7z).
- **For boot-gate users, `bin/gate.sh` keeps the evidence of a build that failed after QEMU started.** It keeps Packer's debug log, the serial console, a screenshot, two live QEMU reads 30 s apart, and the guest's logs read from its disk. It never keeps a disk or box image, and the evidence never changes the verdict. A default run on both releases takes about 80–90 minutes on a 12-CPU KVM host.

## Upgrading

No rebuild is needed: this release changes nothing inside the guest. Templates from this release make an extra directory, `output-<template>-qmp/`, beside the output directory. Run builds from a directory only you and your group can write to, not from `/tmp` itself.

## Known limits

- About 2% of cold Mavericks builds on GitHub's AMD EPYC 7763 runners stall partway through the install, and the build ends with "Timeout waiting for SSH". The cause is not yet known. This release exists to capture the next stall, and `docs/decisions/0040` describes what is read.
- If you build in a directory your group can write to, a member of that group could replace the socket's directory just before QEMU starts and so take control of the guest being built. The plugin allows group-writable directories because a umask of 002 makes them common.

Images and boxes contain Apple's operating system. **Never publish them.**
