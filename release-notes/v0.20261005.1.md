The first release: a Packer plugin and two templates that build Mac OS X VMs
unattended, under QEMU with KVM on Linux.

- **Mac OS X 10.9 Mavericks**, from Apple's own installer, downloaded during
  the build, up to 10.9.5 with Security Update 2016-004.
- **Mac OS X 10.6 Snow Leopard**, from your own retail 10.6 install DVD image
  (build 10A432, checked package by package), up to 10.6.8 with Security
  Update 2013-004.

Each template makes a Vagrant box with passwordless sudo and SSH. Download a
template zip below, then `packer init .` and `packer build .` as the README
says.

The image, and any box made from it, contain Apple's operating system. Never
publish either one.
