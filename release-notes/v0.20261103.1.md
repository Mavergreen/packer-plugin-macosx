## What improves

- **Cold builds work on Ubuntu 26.04 hosts.** The plugin prepares the install media in a small helper VM that runs your host's own kernel and busybox. That VM ran with QEMU's default CPU model, which has no AVX, and Ubuntu 26.04's busybox uses AVX throughout, so on a 26.04 host (including GitHub's `ubuntu-latest` runners, which are moving to 26.04) every build that had to make its media failed in a few seconds with "privileged operations failed inside the microVM". The helper VM now has the host's CPU. The guest's own CPU model is unchanged.

## Upgrading

No rebuild is needed: this release changes nothing inside the guest, and builds that already had their media cached were never affected.

## Known limits

- About 2% of cold Mavericks builds on GitHub's AMD EPYC 7763 runners stall partway through the install, and the build ends with "Timeout waiting for SSH". The cause is not yet known; `docs/decisions/0040` describes what is read when it happens.
- If you build in a directory your group can write to, a member of that group could replace the QEMU monitor socket's directory just before QEMU starts and so take control of the guest being built. The plugin allows group-writable directories because a umask of 002 makes them common.

Images and boxes contain Apple's operating system. **Never publish them.**
